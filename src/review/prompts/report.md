# Accept the report

Compare the completed draft and editorial versions. Restore lost detail and accept the final canonical report using the report template embedded below. Return the complete self-contained report, preserving coverage, research context and every evidence gap.

Account for every worker finding with `decisions.sourceId = '<stage>:<finding id>'`. Explain retained, merged, excluded or open findings. Keep retained report IDs visible in Markdown. The decision stage assesses this accepted report.

## Acceptance checklist

- [ ] All review inputs are included or noted as missing.
- [ ] Important claims have been checked. Duplicate findings are merged. Disagreements are resolved or recorded as open questions.
- [ ] The report gives the consolidation worker’s conclusions instead of joining worker reports together.
- [ ] The initial risks have been revisited using the completed review. The scope recommendation is supported by evidence.
- [ ] The report contains enough background and evidence to make sense on its own, including what was not verified.
- [ ] Every selected check has a result. All template placeholders are filled in or removed with their optional sections.
- [ ] The accepted report is returned directly to the caller and supplied to the GitHub subscriber.
