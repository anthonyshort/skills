# Plan a split-only review

Return a split-only report with Assessment, Risk and scope, Split plan and CI status headings. Read the sibling [split-pr skill](../split-pr/SKILL.md) when available. State what was inspected and that full implementation and rule review were deferred.

Use the accepted setup result, pinned diff and available context to propose useful independently reviewable boundaries. Explain dependencies and a viable order.
